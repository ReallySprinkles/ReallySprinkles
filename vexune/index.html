Vexune

1.0 Alpha / GPL-3.0
★ 420

Advanced TikTok iOS tweak (.dylib) delivering ultimate control, feature unlocks, and deep customization straight from your device.

Download Alpha (.dylib) GitHub ↗ Discord ↗

Alpha Release. Features are actively in testing across various iOS and TikTok versions. Bug reports and compatibility logs should be shared directly in our Discord community.

Features

Region spoofing and bypass regional restrictions effortlessly
Ad-free browsing experience across all feeds and live streams
Direct 4K video and photo downloading without watermarks
Live stream recording and chat playback enhancements
Custom speed multiplier options for feeds and stories
Copy profile bios, comments, and captions with a single tap
Anonymous viewing for live broadcasts and stories
Enhanced dark mode appearance and layout customizations
English and multilingual localization support

Compatibility

Vexune relies on modern injection methods compatible with standard jailbreaks (Sileo/Zebra) as well as modern sideloading tools (TrollStore, Esign, AltStore).

TikTok Version Jailbreak (Rootless/Rootful) Sideload / TrollStore
v30.x and earlier unsupported unsupported
v32.0 to v34.5 not tested supported
v35.0 and later fully supported fully supported

Make sure you use a compatible dylib loader corresponding to your injection environment. Check release notes for specific TikTok app version requirements per alpha build.
